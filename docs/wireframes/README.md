## 1. Objetivo

Diseñar los wireframes de baja fidelidad correspondientes a las seis pantallas principales de EduMonitor AI, con el propósito de definir la estructura visual, la distribución de componentes, la navegación y los elementos de interacción de la aplicación web antes de su implementación.

Los diseños toman como referencia los requisitos de interfaz documentados en `docs/requirements/requisitos.md`.

## 2. Wireframes desarrollados

### 2.1. Inicio de sesión

![Wireframe de inicio de sesión](01-login.png)

Representa el acceso de los docentes a EduMonitor AI mediante correo institucional y contraseña, incluyendo elementos de validación, mensajes de error y estado de autenticación.

### 2.2. Listado de cursos

![Wireframe de cursos](02-cursos.png)

Representa los cursos autorizados del docente, incorporando búsqueda, filtros, información general de cada curso y controles relacionados con la sincronización de datos de Moodle.

### 2.3. Dashboard académico

![Wireframe del dashboard](03-dashboard.png)

Presenta la estructura del panel de indicadores académicos, incluyendo estadísticas generales, gráficos, información del rendimiento del curso y acceso a las fichas individuales de estudiantes.

### 2.4. Ficha individual del estudiante

![Wireframe de ficha individual](04-ficha-estudiante.png)

Representa la información académica individual del estudiante, incluyendo datos generales, calificaciones, actividades, indicadores de desempeño, progreso y evidencias relacionadas con alertas.

### 2.5. Alertas académicas

![Wireframe de alertas](05-alertas.png)

Define la estructura para consultar alertas académicas, aplicar filtros, identificar estudiantes en riesgo y visualizar las evidencias que justifican las alertas generadas.

### 2.6. Chat con el agente de IA

![Wireframe del chat](06-chat-ia.png)

Representa la interfaz de conversación entre el docente y el agente de inteligencia artificial, incluyendo selección de curso, historial de mensajes, preguntas sugeridas, respuestas fundamentadas, recomendaciones y trazabilidad de las consultas.

## 3. Características del diseño

Los wireframes fueron elaborados siguiendo los principios de diseño de baja fidelidad:

- Uso de blanco, negro y escala de grises.
- Representación simplificada de componentes visuales.
- Organización mediante contenedores, campos, botones y elementos de navegación.
- Jerarquía visual clara y distribución consistente de espacios.
- Enfoque en la arquitectura de información y los flujos principales de interacción.

## 4. Consideraciones

Estos wireframes representan una propuesta estructural inicial y no constituyen interfaces funcionales ni diseños visuales definitivos.
